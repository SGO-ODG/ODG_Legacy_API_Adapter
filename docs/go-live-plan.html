1. Objective

Cut over legacy insurance company customers from the existing CodeIgniter PHP API to the new ODG Legacy API Adapter (Node.js / Express on Azure App Service) without any changes to the customer integration. Customers continue using the same HTTP paths, headers, XML request bodies, and response shapes they currently use. The adapter translates calls to ODG API v1.2 behind the scenes.

The go-live is phased by endpoint readiness. Endpoints with completed testing and resolved discrepancies go live first. The Reserve Calculator is excluded until testing is complete and results are verified.

6. Rollback Plan

The legacy PHP API remains running throughout Phases 1–4. Rollback is a DNS/routing change only — no code deployment required. The adapter and legacy PHP API can run in parallel indefinitely.

TriggerRollback ActionOwnerTime to Execute
Adapter returning unexpected errors (5xx) for a customer Revert DNS / routing rule to point customer traffic back to legacy PHP server ODG API Team / Infra < 5 minutes
Customer reports incorrect response content Revert routing for that customer; investigate discrepancy using Application Insights + usage log ODG API Team < 10 minutes
ODG API v1.2 upstream outage Revert all customers to legacy PHP (which uses different upstream data source) ODG API Team < 15 minutes
OAuth token refresh failure (all requests failing auth) Revert routing; check Key Vault secret rotation or OAuth server availability ODG API Team < 10 minutes
PostgreSQL connectivity failure Revert routing; check VNet / private endpoint configuration ODG API Team / Infra < 10 minutes
Rollback is low-risk: Because the legacy PHP API continues to run on the existing infrastructure throughout the cutover process, rollback for any customer is a single routing change. No data migration is involved. No customer data is stored in the adapter — only usage logs.
Do not decommission the legacy PHP API (Phase 5) until all customers are on the adapter and have been stable for a minimum of 4 weeks. Premature decommission removes the rollback option.
