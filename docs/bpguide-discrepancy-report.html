Discrepancy Categories

Category 1 — HTTP Status Mismatch: Malformed ICD Codes 13 tests

All 13 HTTP status mismatches involve ICD codes in non-standard formats that the legacy PHP database resolved via loose matching but ODG v1.2 rejects with a 404 response.

TestICD / URLLegacy StatusAdapter StatusRoot Cause
Symetra-ODGDEMO-TEST-1 /restws/bpguide/icd/010.013/format/json 200 404 ICD-9 code with leading zero in the first segment. Legacy resolved it; ODG v1.2 returns no results.
Symetra-ODGDEMO-TEST-5 /restws/bpguide/icd/150.41/format/json 200 404 3-digit numeric ICD-9 code with decimal. ODG v1.2 does not recognize this variant.
Symetra-ODGDEMO-TEST-6, -7, -9, -10, -11, -14 26615, 27654, 44005, 46255, 50545, 61458 200 404 5-digit numeric codes without a decimal point (non-standard ICD-9 format). Legacy resolved them via integer lookup; ODG v1.2 requires standard decimal notation.
Symetra-ODGDEMO-TEST-12 /restws/bpguide/icd/5522.32XA/format/json 200 404 Malformed code mixing a numeric prefix with an ICD-10 extension suffix (XA). Legacy matched on the numeric prefix; ODG v1.2 rejects the full string.
Symetra-ODGDEMO-TEST-17 /restws/bpguide/icd/825.10/format/json 200 404 ICD-9 code with trailing zero after decimal. Legacy resolved it; ODG v1.2 returns no results.
Symetra-ODGDEMO-TEST-30 /restws/bpguide/icd/A49.02:/format/json 200 404 Valid ICD-10 code A49.02 with a trailing colon. Legacy stripped it silently; adapter forwards as-is causing ODG to reject it. Same trailing-punctuation pattern seen in UR Advisor.
Origami-ODGWEBSVCS-TEST-29 /restws/bpguide/icd/111.1111 200 404 Numeric code with too many decimal digits (4 after decimal). Invalid ICD-9/10 format. Legacy returned a result; ODG v1.2 does not recognize this code.
jwsoftware-ODGWEBSVCS-TEST-5 /restws/bpguide/icd/M45.20 200 404 Valid ICD-10 format but ODG v1.2 returns no guideline data for this specific code. Possible data gap in ODG for ankylosing spondylitis with cervical involvement.
Root Cause (Symetra + Origami): The legacy PHP database used loose/fuzzy ICD code matching — stripping trailing punctuation, normalizing decimal positions, and falling back on integer prefix lookups. The adapter forwards ICD codes as received to ODG v1.2, which requires strict standard notation.
Recommendation (High Priority): Add ICD code sanitization in the adapter's BPGuide request handler to:
  • Strip trailing non-alphanumeric characters (colons, dots) from each ICD code
  • Normalize 5-digit numeric codes without decimal to standard ICD-9 format (e.g. 26615 → 266.15)
  • Remove invalid extension suffixes from otherwise numeric codes
This is the same sanitization recommended for UR Advisor trailing-dot codes. For M45.20 returning no results in ODG, confirm with the ODG API team whether guideline data should exist.

Category 2 — Content Mismatch: pt.visits Range Format 2 tests

JohnsEastern-ODGWEBSVCS-TEST-32 and MissouriEmployersMut-ODGWEBSVCS-TEST-13 both return HTTP 200 with valid data, but the physical therapy visits value for the last PT guideline item differs: legacy returns "1", adapter returns "1-2".

TestPropertyLegacy ValueAdapter Value
JohnsEastern-ODGWEBSVCS-TEST-32 item[icd=726.10].pt.item[4].visits 1 1-2
MissouriEmployersMut-ODGWEBSVCS-TEST-13 item[icd=M75.52].pt.item[4].visits 1 1-2
Root Cause: ODG v1.2 returns a range (1-2) for this PT guideline entry. The legacy database stored a single integer. The adapter faithfully transmits the ODG response. The legacy value of 1 was likely a truncation of the true range.
Recommendation: Confirm with Product/Clinical whether the range value 1-2 from ODG v1.2 is authoritative. If yes, update test expectations. The adapter behavior is correct.

Category 3 — Content and Format Mismatch: PSWCA-TEST-7 Singleton vs. Array 1 test

PSWCA-ODGWEBSVCS-TEST-7 is a multi-ICD request (S93402~S8391~S8392~S9001~S8001). The legacy PHP API returned bp, activitymod, and pt as singleton objects when only one pathway entry exists; the adapter correctly returns them as arrays. Additionally, legacy returned XML despite /format/json in the URL; the adapter correctly returns JSON.

Assessment: The adapter's behavior is correct on both counts — returning JSON for a /format/json URL and using consistent arrays. The legacy singleton-vs-array behavior was a known PHP serialization quirk for single-pathway codes. Update test expectations. Customers relying on singleton objects for single-pathway responses need to handle arrays.

Category 4 — Expected Diffs: Adapter Returns Data for Previously Empty ICD Codes ~26 tests (PSWCA)

For PSWCA-ODGWEBSVCS, the legacy database returned an empty guideline result for approximately 26 ICD-10 codes (primarily upper-extremity and lower-extremity injury codes such as S62.397, S80.01, S93.402, S70.01). The adapter returns full guideline data because ODG v1.2 has broader coverage for these codes.

Assessment: No fix required. The adapter returns richer guideline data for codes that legacy had no data for. Update test expectations. This is an improvement in coverage for PSWCA customers.

Category 5 — Expected Diffs: Extra Activity Modifiers in Adapter Response ~14 tests (MLC, SuncorpAU, CityofFortWorth, JohnsEastern)

The adapter returns additional activity modifier entries not present in the legacy response. ODG v1.2 may return 3 activity modifier items where legacy returned 2, or include supplementary entries at higher indices. Primarily affects MLC-ODGDEMO (4 tests), SuncorpAU-ODGDEMO (5 tests), CityofFortWorth-ODGWEBSVCS (3 tests), and JohnsEastern-ODGWEBSVCS (3 tests).

Assessment: No fix required. ODG v1.2 returns more complete activity modifier data. Update test expectations to accept the additional entries.

Category 6 — Expected Diffs: ICD Code / Name Value Differences ~3 tests

For ICD codes C15 (esophageal cancer) and A09 (infectious gastroenteritis), the adapter returns a different icdcode or name value compared to legacy. ODG v1.2 returns a more specific sub-code or updated description text for these codes.

Assessment: No fix required. The adapter returns values from ODG v1.2 which reflects the current knowledge base. Update test expectations.
